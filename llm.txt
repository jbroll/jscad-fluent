# jscad-fluent API

Fluent wrapper for JSCAD. All methods chainable. REQUIRE NOT IMPORT: `const jf = require('@jbroll/jscad-fluent')
`

## CRITICAL CONSTRAINTS
- Angles: RADIANS (not degrees). Use Math.PI
- Colors: 0-1 range (not 0-255)
- Booleans: all inputs must be same type (all 2D or all 3D)
- All operations return NEW objects (immutable, like standard JSCAD)
- Measurements return values (not chainable)

## TYPES
```
Vec2 = [number, number]
Vec3 = [number, number, number]
RGB = [number, number, number]        // 0-1
RGBA = [number, number, number, number]  // 0-1
Corners = 'edge' | 'chamfer' | 'round'
```

## BOOLEANS & COMBINING -> new instance (inputs must match geometry type)

// Method chaining - accepts spread args, arrays, or mixed
.union(...others)           // a.union(b), a.union(b, c), a.union([b, c])
.subtract(...others)        // a.subtract(b), a.subtract(b, c), a.subtract([b, c])
.intersect(...others)       // a.intersect(b), a.intersect(b, c), a.intersect([b, c])
.minkowski(...others)       // a.minkowski(b), a.minkowski(b, c) - 3D only

// Top-level functions - for combining multiple geometries
jf.union(...geometries)     // jf.union(a, b, c), jf.union([a, b, c]), jf.union(fluentArray)
jf.subtract(...geometries)  // jf.subtract(base, hole1, hole2), jf.subtract(base, [holes])
jf.intersect(...geometries) // jf.intersect(a, b, c), jf.intersect([a, b, c])

.scission() -> FluentGeom3Array  // 3D only: split into disconnected pieces
// const [left, right] = jf.union(a, b).scission()

// Minkowski sum - useful for rounding edges, collision volumes, swept shapes
// Example: rounded cube
jf.cube({ size: 10 }).minkowski(jf.sphere({ radius: 1 }))

## ANCHORS (FluentGeom2 and FluentGeom3, not path2)

// Frame = { origin: Vec3, z: Vec3, x?: Vec3 }. z is the meaning (face normal, hole axis); x fixes spin.
// Names: 'top'|'bottom'|'left'|'right'|'front'|'back', joined with '+' ('top+right'), 'center', or your own.
.withAnchors({ name: Frame, ... }) -> new instance     // frames in the part's local space, follow later transforms
.anchor(name | [dx,dy,dz]) -> { origin, z, x }         // world space; direction names fall back to bounding-box defaults
.anchors?.frames                                       // stored LOCAL frames or undefined; use .anchor(name) for world
.attachTo(parent, parentAnchor, childAnchor, { overlap?: number=0, flip?: boolean=true, spin?: number=0 }) -> new instance
.alignTo(parent, direction, { inset?: number=0, inside?: boolean=false }) -> new instance  // translate only
.subtract(...tools, { carry: { prefix: tool } })       // keeps tool's frames as 'prefix.name'
// union keeps first operand's frames plus new names from the rest; subtract/intersect keep the first operand's only
// hull, expand, offset, extrude, minkowski, scission results have no frames

// Example: plate with a bolt hole, then a bolt pushed 5mm down into it from the top face
const hole = jf.cylinder({ radius: 2, height: 10 }).withAnchors({ axis: { origin: [0,0,2.5], z: [0,0,1] } }).translate([10, 0, 0]);
const plate = jf.cuboid({ size: [40, 40, 5] }).subtract(hole, { carry: { bolt1: hole } });
const bolt = jf.cylinder({ radius: 1.8, height: 20 }).attachTo(plate, 'bolt1.axis', 'bottom', { overlap: 5 });

## GEOMETRY ARRAYS (for hull, hullChain, batch extrusion)

// Array constructors
jf.array(geom1, geom2, ...)      // infers type from first item (requires at least one)
jf.geom2Array(...items)          // typed 2D array (can be empty, use for loops)
jf.geom3Array(...items)          // typed 3D array (can be empty, use for loops)
jf.path2Array(...items)          // typed path array (can be empty, use for loops)

// Create array with .append()
geom1.append(geom2) -> FluentGeom*Array     // creates array from two geometries
array.append(geom3) -> FluentGeom*Array     // adds to array (chainable)

// Array operations - combine into single geometry
.hull() -> FluentGeom*                      // convex hull of all geometries
.hullChain() -> FluentGeom*                 // sequential hull pairs

// 2D arrays only - batch extrusion (extrudes each element)
.extrudeLinear(options) -> FluentGeom3Array
.extrudeRotate(options) -> FluentGeom3Array
.extrudeHelical(options) -> FluentGeom3Array
.extrudeRectangular(options) -> FluentGeom3Array   // also on path arrays
// path arrays
.expand(options) -> FluentGeom2Array

// Items are fluent (FluentGeom2/FluentGeom3/FluentPath2): arr[0].translate(...) works
// filter/slice keep the array class; map returns a plain array
// Transforms on arrays apply to all elements
array.translate([x,y,z]) -> FluentGeom*Array
array.rotate([rx,ry,rz]) -> FluentGeom*Array
// ... all transform methods work on arrays

// Examples:
// Inline array creation (type inferred from items)
const hull2d = jf.array(
  jf.circle({ radius: 5 }),
  jf.circle({ radius: 5 }).translate([20, 0, 0])
).hull();  // -> FluentGeom2

// Using append chain
const hull3d = jf.sphere({ radius: 5 })
  .append(jf.sphere({ radius: 5 }).translate([15, 0, 0]))
  .append(jf.sphere({ radius: 5 }).translate([15, 15, 0]))
  .hullChain();  // -> FluentGeom3

// Loop pattern (use typed constructor for empty start)
let arr = jf.geom2Array();
for (let i = 0; i < 5; i++) {
  arr = arr.append(jf.circle({ radius: i + 1 }).translate([i * 10, 0, 0]));
}
const result = arr.hull();

jf.extrudeFromSlices(options, baseSlice) -> FluentGeom3

## EXAMPLE

```javascript
const jf = require('@jbroll/jscad-fluent');

const model = jf.rectangle({ size: [50, 30] })
  .subtract(jf.circle({ radius: 8 }).translate([15, 0, 0]))
  .expand({ delta: 2, corners: 'round' })
  .extrudeLinear({ height: 20 })
  .union(jf.cylinder({ radius: 3, height: 25 }).translate([20, 10, 0]))
  .colorize(jf.colors.hexToRgb('#3344CC'));

// Multiple objects at once
const holes = [
  jf.cylinder({ radius: 2, height: 10 }).translate([5, 5, 0]),
  jf.cylinder({ radius: 2, height: 10 }).translate([-5, -5, 0])
];
const withHoles = block.subtract(holes);  // array form
const withHoles2 = block.subtract(hole1, hole2);  // spread form

// Top-level union for combining many objects
const allParts = jf.union(part1, part2, part3);
const allParts2 = jf.union([part1, part2, part3]);  // array form

// Or use CSS color names
const redSphere = jf.sphere({ radius: 5 }).colorize(jf.colors.css.red);
```
